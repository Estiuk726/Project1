# FlightMates

See who's on your flight. A social travel app for students flying between South Asia and Europe.

- Build plan: [docs/BUILD_PLAN.md](docs/BUILD_PLAN.md)

## Getting started

Requires Node 22+ and pnpm 10.

```sh
corepack enable
pnpm install
pnpm lint
pnpm typecheck
```
